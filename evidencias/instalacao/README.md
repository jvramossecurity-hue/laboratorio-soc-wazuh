# Evidências da instalação

1. Preparação da máquina virtual Ubuntu Server.
2. Configuração do ambiente e atualização do sistema.
3. Download e verificação de integridade do pacote Wazuh.
4. Instalação do Wazuh Manager.
5. Inicialização e verificação dos serviços.

As capturas de tela serão adicionadas conforme a documentação do laboratório evoluir.
